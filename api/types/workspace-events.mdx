## Overview

The `WorkspaceChangeEvent` type represents all events that occur in the Arkitec workspace. These events are published through the `ChangesService` and can be subscribed to for reactive updates.

## Type Definition

`WorkspaceChangeEvent` is a union type of five different event kinds:

```typescript
type WorkspaceChangeEvent =
  | FilesystemChangedEvent
  | WorkspaceRootChangedEvent
  | RegistryUpdatedEvent
  | AgentCardUpdatedEvent
  | AgentSkillsSyncedEvent;
```

## Event Types

### FilesystemChangedEvent

Emitted when files or directories change in the workspace.

```typescript
interface FilesystemChangedEvent {
  kind: "filesystem.changed";
  type: FileChangeType;
  path: string;
  error?: string;
  rootPath: string | null;
  timestamp: number;
}
```

<ResponseField name="kind" type="literal" required>
  Always `"filesystem.changed"` for this event type.
</ResponseField>

<ResponseField name="type" type="FileChangeType" required>
  The type of filesystem change that occurred.
  
  <Expandable title="FileChangeType Values">
    - `"add"` - File was created
    - `"addDir"` - Directory was created
    - `"change"` - File was modified
    - `"unlink"` - File was deleted
    - `"unlinkDir"` - Directory was deleted
    - `"error"` - An error occurred during watching
  </Expandable>
</ResponseField>

<ResponseField name="path" type="string" required>
  Relative or absolute path to the changed file or directory.
</ResponseField>

<ResponseField name="error" type="string">
  Error message if `type` is `"error"`.
</ResponseField>

<ResponseField name="rootPath" type="string | null" required>
  The workspace root path, or null if not set.
</ResponseField>

<ResponseField name="timestamp" type="number" required>
  Unix timestamp (milliseconds) when the event occurred.
</ResponseField>

### RegistryUpdatedEvent

Emitted when the project registry is updated (projects added, removed, or rescheduled).

```typescript
interface RegistryUpdatedEvent {
  kind: "registry.updated";
  reason: RegistryChangeReason;
  directory?: string;
  projectCount: number;
  timestamp: number;
}
```

<ResponseField name="kind" type="literal" required>
  Always `"registry.updated"` for this event type.
</ResponseField>

<ResponseField name="reason" type="RegistryChangeReason" required>
  The reason for the registry update.
  
  <Expandable title="RegistryChangeReason Values">
    - `"scan"` - Initial workspace scan completed
    - `"register"` - New project was registered
    - `"unregister"` - Project was unregistered
    - `"reschedule"` - Project schedule was updated
    - `"workspace.refresh"` - Entire workspace was refreshed
  </Expandable>
</ResponseField>

<ResponseField name="directory" type="string">
  Optional path to the specific project directory that changed.
  
  Present for `"register"`, `"unregister"`, and `"reschedule"` reasons.
</ResponseField>

<ResponseField name="projectCount" type="number" required>
  Total number of registered projects after this update.
</ResponseField>

<ResponseField name="timestamp" type="number" required>
  Unix timestamp (milliseconds) when the update occurred.
</ResponseField>

## Event Flow

Understanding the typical event sequence:

### Initial Workspace Scan
```
1. workspace.root.changed (if root is set)
2. registry.updated (reason: "scan")
3. agent.card.updated (for each agent found)
```

### Adding a New Agent
```
1. filesystem.changed (type: "addDir") - Directory created
2. filesystem.changed (type: "add") - ark.config.json added
3. filesystem.changed (type: "add") - agent-card.json added
4. registry.updated (reason: "register")
5. agent.card.updated
```

### Modifying Agent Configuration
```
1. filesystem.changed (type: "change") - ark.config.json modified
2. registry.updated (reason: "reschedule")
```

### Updating Agent Card
```
1. filesystem.changed (type: "change") - agent-card.json modified
2. agent.card.updated
```

### Removing an Agent
```
1. filesystem.changed (type: "unlink") - ark.config.json deleted
2. registry.updated (reason: "unregister")
```

## Usage Patterns

### Filtering Events by Type

```typescript
// Only handle registry updates
const unsubscribe = changesService.subscribe((event) => {
  if (event.kind === 'registry.updated') {
    console.log(`Registry updated: ${event.reason}`);
    console.log(`Projects: ${event.projectCount}`);
  }
});
```

### Debouncing Config Changes

```typescript
let debounceTimer: NodeJS.Timeout | null = null;

const unsubscribe = changesService.subscribe((event) => {
  if (event.kind === 'filesystem.changed' && 
      event.path.endsWith('ark.config.json')) {
    
    if (debounceTimer) clearTimeout(debounceTimer);
    
    debounceTimer = setTimeout(() => {
      handleConfigUpdate(event.path);
    }, 200);
  }
});
```

### Tracking Agent Lifecycle

```typescript
const agentLifecycle = new Map<string, 'active' | 'removed'>();

changesService.subscribe((event) => {
  if (event.kind === 'registry.updated' && event.directory) {
    if (event.reason === 'register') {
      agentLifecycle.set(event.directory, 'active');
      console.log(`Agent registered: ${event.directory}`);
    } else if (event.reason === 'unregister') {
      agentLifecycle.set(event.directory, 'removed');
      console.log(`Agent removed: ${event.directory}`);
    }
  }
});
```

## Integration with InspectorService

The `InspectorService` uses these events internally:

```typescript
class InspectorService {
  setupChangeSubscriptions(): Result<void, RegistryError> {
    this.unsubscribeFromChanges?.();
    
    this.unsubscribeFromChanges = this.changes.subscribe((event) => {
      this.onWorkspaceEvent(event);
    });
    
    return r.success(undefined);
  }
  
  private onWorkspaceEvent(event: WorkspaceChangeEvent): void {
    // Handle workspace root changes
    if (event.kind === 'workspace.root.changed') {
      this.refreshWorkspace();
      return;
    }
    
    // Handle agent card updates
    if (event.kind === 'agent.card.updated') {
      this.scheduleOrgRegeneration();
      return;
    }
    
    // Handle filesystem changes
    if (event.kind === 'filesystem.changed') {
      if (event.path.endsWith('ark.config.json')) {
        this.handleConfigChange(event);
      } else if (event.path.endsWith('agent-card.json')) {
        this.scheduleOrgRegeneration();
      }
    }
  }
}
```
