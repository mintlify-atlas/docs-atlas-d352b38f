---
title: FileSystemService
description: Service for safe filesystem operations within the workspace root
---

The `FileSystemService` provides safe filesystem operations scoped to a workspace root directory. All paths are validated to ensure they remain within the workspace, preventing directory traversal attacks.

## Injection

The service is injectable via dependency injection:

```typescript
import { inject, injectable } from "tsyringe";
import { FileSystemService } from "@/main/services/fs/fs.service";

@injectable()
export class MyService {
  constructor(
    @inject(FileSystemService) private readonly fss: FileSystemService
  ) {}
}
```

## Public Methods

### openFolder

Sets the workspace root directory to a new location.

<ParamField path="directory" type="string" required>
  Absolute path to the new workspace root directory
</ParamField>

<ResponseField name="success" type="boolean">
  Indicates if the operation succeeded
</ResponseField>

<ResponseField name="data" type="string">
  The resolved absolute path to the new workspace root
</ResponseField>

<ResponseField name="error" type="FsError">
  Error details if the operation failed
</ResponseField>

**Possible Errors:**
- `InvalidPathError` - Folder path is empty or invalid
- `RootAccessError` - Cannot access or create the directory

**Behavior:**
- Resolves the path to an absolute path
- Validates that the directory exists or can be created
- Saves the folder path to persistent storage
- Rolls back to the previous root if validation fails

<CodeGroup>
```typescript Example
const result = await fss.openFolder("/home/user/projects");

if (result.success) {
  console.log(`Workspace root: ${result.data}`);
} else {
  console.error(`Failed: ${result.error.message}`);
}
```
</CodeGroup>

### listTree

Returns a recursive tree structure of all files and directories in the workspace.

<ResponseField name="success" type="boolean">
  Indicates if the operation succeeded
</ResponseField>

<ResponseField name="data" type="FileTreeNode">
  The root node of the file tree
</ResponseField>

<ResponseField name="error" type="FsError">
  Error details if the operation failed
</ResponseField>

**Possible Errors:**
- `TreeReadError` - Failed to read the directory tree

<CodeGroup>
```typescript Example
const result = await fss.listTree();

if (result.success) {
  const printNode = (node: FileTreeNode, indent = 0) => {
    const prefix = "  ".repeat(indent);
    console.log(`${prefix}${node.name} ${node.type === "directory" ? "/" : ""}`);
    
    if (node.type === "directory" && node.children) {
      for (const child of node.children) {
        printNode(child, indent + 1);
      }
    }
  };
  
  printNode(result.data);
}
```

```typescript FileTreeNode Type
interface FileTreeNode {
  name: string;
  path: string;
  type: "file" | "directory";
  children?: FileTreeNode[];
}
```
</CodeGroup>

## Complete Usage Example

<CodeGroup>
```typescript Full Workflow
import { inject, injectable } from "tsyringe";
import { FileSystemService } from "@/main/services/fs/fs.service";

@injectable()
export class DataManager {
  constructor(
    @inject(FileSystemService) private readonly fss: FileSystemService
  ) {}

  async initialize(workspaceRoot: string) {
    // Open workspace
    const openResult = await this.fss.openFolder(workspaceRoot);
    if (!openResult.success) {
      throw new Error(`Cannot open workspace: ${openResult.error.message}`);
    }

    // Create data directory
    const mkdirResult = await this.fss.mkdir("data", true);
    if (!mkdirResult.success) {
      console.warn(`Failed to create data dir: ${mkdirResult.error.message}`);
    }
  }

  async saveData(filename: string, data: object) {
    const content = JSON.stringify(data, null, 2);
    const result = await this.fss.writeFile(`data/${filename}`, content);
    
    if (result.success) {
      console.log(`Saved to: ${result.data}`);
    } else {
      console.error(`Save failed: ${result.error.message}`);
    }
  }

  async loadData(filename: string): Promise<object | null> {
    const result = await this.fss.readFile(`data/${filename}`);
    
    if (result.success) {
      try {
        return JSON.parse(result.data.content);
      } catch (error) {
        console.error(`Parse failed: ${error}`);
        return null;
      }
    } else {
      console.error(`Load failed: ${result.error.message}`);
      return null;
    }
  }

  async listDataFiles(): Promise<string[]> {
    const treeResult = await this.fss.listTree();
    if (!treeResult.success) {
      return [];
    }

    const dataNode = treeResult.data.children?.find(
      (node) => node.name === "data" && node.type === "directory"
    );

    if (!dataNode || !dataNode.children) {
      return [];
    }

    return dataNode.children
      .filter((node) => node.type === "file")
      .map((node) => node.name);
  }

  async archiveFile(filename: string) {
    // Create archive directory
    await this.fss.mkdir("data/archive", true);

    // Move file
    const result = await this.fss.renamePath(
      `data/${filename}`,
      `data/archive/${filename}`
    );

    if (result.success) {
      console.log(`Archived: ${filename}`);
    }
  }

  async cleanupOldFiles() {
    const deleteResult = await this.fss.deletePath("data/archive");
    if (deleteResult.success) {
      console.log("Archive cleaned up");
    }
  }
}
```
</CodeGroup>

## Error Handling

All methods return a `Result<T, E>` type:

```typescript
const result = await fss.readFile("config.json");

if (result.success) {
  const content = result.data.content;
} else {
  console.error(`Error [${result.error.code}]: ${result.error.message}`);
}
```

### Common Error Codes

- `InvalidPathError` - Path is empty, malformed, or attempts to escape the workspace root
- `RootAccessError` - Cannot access or create the workspace root directory
- `FileAccessError` - Cannot read or access the specified file
- `FileWriteError` - Cannot write to or create a file
- `NotAFileError` - Path points to a directory when a file was expected
- `PathRenameError` - Cannot rename or move the path
- `PathDeleteError` - Cannot delete the path
- `TreeReadError` - Cannot read the directory tree

---

## Security

The service enforces strict path validation:

- All relative paths are resolved against the workspace root
- Path traversal attempts (e.g., `../../../etc/passwd`) are blocked
- Operations are confined to the workspace root directory
- Symbolic links are resolved and validated
